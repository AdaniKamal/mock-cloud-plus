# Mock Cloud+ ☁️

A simple mock exam application I built to help with **CompTIA Cloud+ (CV0-004)** study and revision.

The project started as a way to organize practice questions collected from multiple study sources into one simple, interactive exam environment.

## Features

* Automatic scoring
* Review correct answers after submission
* Attempt history
* Reset progress
* Light and dark mode
* Responsive interface

## Purpose

Instead of going through scattered practice questions manually, this tool provides a simple way to:

* Practice Cloud+ questions in one place
* Simulate a mock exam
* Review incorrect answers
* Track previous attempts

## Tech Stack

* JavaScript
* React
* CSS
* Vercel
